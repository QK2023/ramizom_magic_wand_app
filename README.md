# Ramizom Magic Wand

A conversation-first Windows desktop AI client built with Flutter. It can see your screen, draw on it, read files, and talk with you by voice, using any OpenAI-compatible model API.

> **This project was generated by AI.** Almost all of the code, tests, and documentation were written by AI coding assistants (Claude) under human direction. It has had limited human review. Read the code before you trust it, expect rough edges, and treat it as experimental software. See [Disclaimer](#disclaimer).

## Highlights

- **Chat** with streaming replies, stop/retry/copy, rendered Markdown, code highlighting, tables and LaTeX. Local history with search, pin, rename, delete and Markdown export.
- **Screen context**: share your screen on demand; the app window and all overlays are excluded from captures.
- **Screen annotations**: the assistant can circle, underline, point at and write notes on real UI elements (found via UI Automation and OCR), or use a separate whiteboard window.
- **Voice**: on-device speech recognition (SenseVoice + Silero VAD: Chinese, English, Cantonese, Japanese, Korean) and spoken replies with Microsoft Edge neural voices.
- **Learning mode**: step-by-step walkthroughs that watch the screen, whiteboard practice, and spaced-repetition review notes.
- **Files**: attach images, PDFs, text and source code to a message.
- **Providers**: DeepSeek, or any OpenAI-compatible API (OpenRouter, local servers, and so on).
- English and Chinese UI, light/dark themes.

See [docs/FEATURES.md](docs/FEATURES.md) for the full details of each feature.

## Requirements

- Windows 10/11 (the only supported platform; the macOS/Linux/Android folders are unmodified Flutter scaffolding)
- [Flutter](https://docs.flutter.dev/get-started/install/windows) with Dart SDK `^3.12.2` and Visual Studio 2022 with the "Desktop development with C++" workload
- An API key for DeepSeek or another OpenAI-compatible provider

## Getting started

```powershell
git clone https://github.com/QK2023/ramizom_magic_wand_app.git
cd ramizom_magic_wand_app

# Download the speech-recognition model (~240 MB, not stored in git)
powershell -ExecutionPolicy Bypass -File scripts/download_models.ps1

flutter pub get
flutter run -d windows
```

Then open **Settings → AI connection**, choose a provider and paste your API key.

Without the speech model the app still runs; only voice input is unavailable.

To build a release: `flutter build windows --release`. The output is in `build/windows/x64/runner/Release/`; keep the `.exe` together with its DLLs and `data` folder.

## Configuration

| Provider | Endpoint | Notes |
| --- | --- | --- |
| DeepSeek | `api.deepseek.com` | Built-in model menu and thinking depth |
| Custom API | any OpenAI-compatible base URL ending at the API version (e.g. `https://openrouter.ai/api/v1`) | HTTPS required except for localhost |

API keys are stored with `flutter_secure_storage`. Nothing is hard-coded and no key is ever committed.

## Privacy

- Conversations, shortcuts and attachments are stored locally under the app support directory (`workspace/`) as unencrypted JSON.
- Screenshots and attachments are sent to **your configured AI provider** only with a message, and screenshots only while sharing is on.
- Speech recognition runs on-device. **Spoken replies are synthesized by Microsoft's online Edge "Read aloud" service, so the text being read is sent to Microsoft.** This uses an unofficial, undocumented endpoint (see [Disclaimer](#disclaimer)).
