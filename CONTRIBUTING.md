# Contributing

Thanks for helping out! This project is largely AI-generated, so careful human review is especially valuable.

1. Fork and create a branch.
2. Run `scripts/download_models.ps1` once, then `flutter pub get`.
3. Make your change with tests where practical.
4. Make sure `flutter analyze` and `flutter test` pass.
5. Open a pull request describing what and why. AI-assisted contributions are welcome; please say so and review the output yourself.

User-visible strings live in `lib/l10n/app_strings.dart` (English and Chinese). Never commit API keys or personal data.
